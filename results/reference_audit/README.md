# Bibliographic identity audit

The revised report contains 44 references. All 32 DOI-bearing entries returned HTTP 200 title metadata from Crossref on 3 November 2026 IST (2 November UTC). `doi_metadata.json` retains the retrieved public metadata and query timestamp. Report numbering is the key of each record.

This audit checks bibliographic identity. It is not a replication of the cited studies or proof that their metrics are comparable to HeatCast. The report reviews heatwave definitions, warning practice, heat prediction, numerical forecast post-processing and foundational model/evaluation sources. It uses journal volume years for Domeisen et al. (2023), Nairn and Fawcett (2015), and Price et al. (2025), which differ from online-first dates.

The Schaake shuffle DOI is `10.1175/1525-7541(2004)005<0243:TSSAMF>2.0.CO;2`. The report replaces the ETCCDI mirror citation with Alexander et al. (2006), DOI `10.1029/2005JD006290`. Official documentation and publication pages are listed separately in the report with access dates.
